# Gestion hôtelière – Abonnements SaaS

Application web de gestion d'hôtels et résidences : essai gratuit de 30 jours, formules payantes (mensuel / annuel), page « Mon abonnement », limites contrôlées côté serveur et espace administrateur plateforme.

- Frontend : `index.html` (statique, aucun build) – déployé sur Vercel.
- Backend : Supabase (projet `gestion-hoteliere`), sécurité par RLS et fonctions serveur.
